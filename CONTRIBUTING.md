# Contributing to Developer Cockpit

Thank you for your interest in contributing to Developer Cockpit.

## Scope of this Repository

This repository contains public-facing documentation, specifications, the Plugin SDK, and community resources for Developer Cockpit.

## Ways to Contribute

- **Plugin Development:** Build plugins using the `@developer-cockpit/plugin-sdk` (see `docs/plugin-sdk/`).
- **Documentation:** Improve technical documentation, architectural guides, and tutorials in `docs/`.
- **Feedback & Feature Requests:** Open an issue to discuss proposed capabilities, workflow improvements, or platform compatibility feedback.

## Guidelines

1. **Be Respectful:** Adhere to our [Code of Conduct](./CODE_OF_CONDUCT.md).
2. **Clear Proposals:** When submitting documentation updates or feature proposals, reference the relevant architectural modules.
3. **Security Reports:** Please do not submit security vulnerabilities via public issues. Follow the instructions in [SECURITY.md](./SECURITY.md).
